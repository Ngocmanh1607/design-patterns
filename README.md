# Design Patterns · OOP · SOLID — khóa học tương tác

Khóa học tương tác bằng tiếng Việt: 6 bài OOP, 5 nguyên lý SOLID và 23 design pattern (Gang of Four), có sơ đồ động, code mẫu và ví dụ Android / iOS / Flutter.

- `index.html`: bản đã build, GitHub Pages phục vụ trực tiếp file này.
- `source/`: mã nguồn React + Motion (Vite).

## Build lại
```bash
cd source
npm install
npm run build        # tạo dist/index.html (một file duy nhất)
cp dist/index.html ../index.html
```
